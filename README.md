## 📌 Project Overview

**Intelligent Manufacturing Systems & AI (IMS-AI)** explores the application of computational tools, parametric modelling and artificial intelligence concepts in modern manufacturing systems.

The project focuses on using Python-based automation and computer-aided design tools to develop, analyse and understand engineering models and manufacturing-related applications.

Through practical coding exercises and modelling tasks, this repository aims to demonstrate how digital technologies can improve design efficiency, automation, accuracy and productivity in manufacturing.

## 🎯 Objectives

- Explore the integration of Artificial Intelligence with manufacturing systems.
- Understand parametric and computational 3D modelling.
- Develop engineering models using Python and CadQuery.
- Apply computational methods to engineering design problems.
- Understand the role of automation and digital technologies in modern manufacturing.

## 💻 Working Methodology

The general workflow for computational modelling activities is:

1. **Problem Identification:** Understand the engineering problem and define the modelling requirements.
2. **Parametric Design:** Define geometric parameters and design constraints.
3. **Computational Modelling:** Develop 3D models using Python and CadQuery.
4. **Model Evaluation:** Inspect geometry and verify relevant design parameters.
5. **Export & Documentation:** Export completed models and document the results.
